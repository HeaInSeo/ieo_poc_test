# ieo_poc_test

[Console Coordinator PoC](https://github.com/HeaInSeo/ieo_poc)의 GitHub 동작 시험용 저장소입니다.
합성 시험 파일만 사용하는 공개 샌드박스이며, 실사용 프로젝트의 개발 저장소와 분리합니다.

## 사용 범위

- 시험 브랜치와 PR 생성, CI 결과 수집, 승인된 head SHA에 대한 조건부 병합
- 정상·실패·누락·다른 SHA·같은 이름의 체크를 구분하는 P07/P23 시험
- 시험 저장소 안에서만 수행하는 보호 설정·권한 변경과 복원

GitHub Actions는 이 저장소의 CI 실행 수단입니다. 컨테이너 이미지 저장소(GHCR)는 별도 자산입니다.

## 초기 준비 기준

- 기본 브랜치: `main`
- 기본 CI: `.github/workflows/bootstrap.yml`의 `repository-smoke`
- CI는 메타데이터 JSON 구문, 필수 안내 파일, 공백 오류 및 실제 체크아웃 SHA를 확인합니다.
- 초기 main 보호: PR 필수, 최신 기준 브랜치의 필수 CI, 관리자 포함, force push·브랜치 삭제 금지
- 기본 `GITHUB_TOKEN`: 읽기 전용. Actions의 PR 작성·승인 권한은 끕니다.

이 CI는 연결 확인용입니다. 후보가 수정할 수 있는 Actions 체크만으로 독립 판정을 충족했다고 간주하지 않습니다.
P07/P23의 기대값·시나리오·예산은 해당 작업의 첫 실행 전에 별도로 고정해야 합니다.
이 저장소의 초기 준비나 CI 성공을 PoC 작업·실험의 검수 완료 수에 넣지 않습니다.

## 역할별 GitHub 자격: 미연결

- 개발: 이 저장소 하나에 한정한 단기 GitHub App 설치 토큰. 개발·교정 단계에서만 사용하고 검토 단계에서는 폐기합니다.
- Guardrail: 고정 SHA와 실제 저장소 설정을 조회하는 읽기 권한. 코드 push·정책 변경·병합 권한을 부여하지 않습니다.
- 코디네이터/독립 검사 발행: 개발과 분리한 권한으로 보호 설정을 대조하고, 승인된 SHA의 판정을 발행·소비합니다.
- 자격 발급과 교체는 사용자 소관입니다. 호스트의 개인 `gh` 로그인 자격을 역할 컨테이너에 전달하지 않습니다.

외부 독립 판정 App과 역할별 자격은 아직 구성하지 않았습니다. 보호 규칙의 검사 출처 고정과 실제 권한 거부는 후속 검증 대상입니다.
토큰·키·개인정보·실제 프로젝트 자료를 이 저장소에 넣지 않습니다.
